# 좀비 런 (GPS 좀비 추격 게임)

실제 GPS 위치를 이용해서, 실제로 뛰어야 좀비 무리를 따돌릴 수 있는 러닝 게임 프로토타입입니다.

배포 주소: https://minable17-glitch.github.io/zombie-run/

## 실행 방법

Node.js 22.22.2 이상을 사용합니다. 새 보안 버전은 DB 마이그레이션과
`zombie-auth` 함수 배포가 함께 필요합니다. 운영 반영 순서는
[DEPLOYMENT.md](DEPLOYMENT.md)를 먼저 확인하세요. 프런트엔드만 배포하면 로그인과 그룹 기능이 동작하지 않습니다.

```bash
npm ci
npm test
npm run dev
```

좀비가 도로를 따라오게 하려면 [OpenRouteService](https://openrouteservice.org/dev/#/signup)에서 무료 API 키를
발급받아 `zombie-run/.env.local`에 `VITE_ORS_API_KEY=발급받은키`로 넣어주세요 (git에는 안 올라감).
GitHub Pages 배포용으로는 저장소 Settings → Secrets and variables → Actions에 `ORS_API_KEY`라는 이름으로
등록해두면 배포 워크플로우가 자동으로 가져다 씁니다. 키가 없어도 게임은 정상 동작하고, 좀비는 직선으로만
쫓아옵니다.

관리자가 좀비 순찰 지도를 저장하려면 Supabase 프로젝트가 하나 필요합니다 (새싹책방과 같은 프로젝트를
별도 테이블로 함께 씁니다). 자세한 건 아래 "관리자용 좀비 경로 만들기" 항목을 참고하세요. `.env.local`에
`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`를 넣으면 로컬에서도 저장이 됩니다. 이게 없어도 관리자
화면에서 저장만 안 될 뿐, 게임 자체(자유/제한구역 모드)는 그대로 잘 동작합니다.

Geolocation API는 보안 컨텍스트(HTTPS 또는 localhost)에서만 동작합니다.
`npm run dev`는 `@vitejs/plugin-basic-ssl`로 자체 서명 인증서를 사용해 https로 켜지므로,
같은 와이파이의 휴대폰에서 `https://<PC의 로컬 IP>:5173` 으로 접속하면 인증서 경고를 무시하고
GPS 테스트를 해볼 수 있습니다. 실제 배포 시에는 Vercel/Netlify 등 HTTPS를 지원하는 곳에 올리세요.

## 게임 규칙 (MVP)

- 시작 화면에서 목표 페이스(5'30"/6'00"/6'30"/7'00" per km)를 고릅니다. 좀비는 그 페이스 속도로 쫓아오고,
  화면 상단에는 내 실시간 페이스(최근 30초 기준)와 목표 페이스가 함께 표시됩니다 — 목표보다 느려지면
  좀비가 따라잡히기 시작해요.
- 시작 버튼을 누르면 위치 권한을 요청하고 바로 러닝이 시작됩니다.
- 시작 60초 뒤 좀비 1~2마리가 근처에 등장하고, 이후 90초마다 추가로 등장합니다 (동시에 최대 4마리까지만
  존재 — 러닝을 재밌게 만드는 정도의 긴장감이 목표라 무리를 크게 늘리지 않습니다).
- 좀비는 항상 **지금 달리고 있는 방향의 뒤쪽**에서만 등장하고, 아이템(모래시계)은 **앞쪽**에 놓입니다.
  그래서 방향을 이리저리 판단할 필요 없이 "그냥 계속 앞으로 달리기"가 곧 도망치는 방법이 됩니다 (15m
  이상 움직이기 전까지는 아직 달리는 방향을 몰라서 무작위 방향에서 등장해요).
- **누군가 미리 좀비 경로를 만들어둔 장소**에서 시작하면(시작 화면 하단의 "🛠️ 내 좀비 경로 만들기"에서
  계정을 만들고 직접 만들 수 있어요) 동적 스폰 대신 그 경로를 그대로 씁니다. 경로의 맨 처음 점이 아니라
  **지금 내 위치에서 가장 가까운 지점**부터 좀비가 순찰을 시작해서, 어디서 출발하든 바로 근처에 좀비가
  있어요. 좀비는 경로를 왕복 순찰하다가 플레이어가 40m 안으로 들어오면 추격을 시작하고, 100m 이상
  벌어지면 다시 순찰로 돌아갑니다. 자세한 건 아래 "내 좀비 경로 만들기" 항목을 참고하세요.
- 시작 화면에서 **자유 모드**(제한 없음) 또는 **제한구역 모드**(시작 위치 기준 300m~2km 반경)를 고를 수
  있습니다. 제한구역 모드에서는 좀비/아이템이 그 반경 안에서만 등장하고, 반경 밖에 누적 1시간 넘게
  있으면 생명이 1개씩 줄어듭니다.
- **"👥 그룹으로 같이 뛰기"**(따로 모드): 방장이 방을 만들어 코드를 공유하면, 참가자들이 코드로
  들어와 대기하다가 방장이 시작을 누르면 전원이 같은 설정(페이스/모드)으로 동시에 게임을 시작합니다.
  좀비는 각자 따로 만나지만(각자 폰에서 독립적으로 계산), 화면 오른쪽 👥 배지를 누르면 다른 참가자들의
  달린 거리·체력·생존 상태를 5초마다 실시간으로 볼 수 있어요. 참가자는 로그인 없이 닉네임만으로 참가할
  수 있고, 방 만들기 화면에서 방장이 누군가 만들어둔 좀비 지도를 하나 고르면(자유/제한구역 모드 대신)
  참가자 전원이 그 지도의 순찰 경로로 시작합니다 — 대기실에 뜨는 지도 이름을 보고 다같이 그 장소로
  모여서 시작하면 돼요.
- 좀비는 실제 플레이어 위치를 향해 다가옵니다. OpenRouteService API 키가 설정돼 있으면 실제 도로/인도
  경로를 따라 걸어오고(15초 또는 내가 60m 이상 움직일 때마다 경로 재계산), 키가 없거나 요청이 실패하면
  자동으로 직선 이동으로 대체됩니다. 12m 이내로 붙잡히면 체력(하트)이 1 깎입니다.
- 모래시계(⏳)를 얻으면 10초간 모든 좀비의 이동이 멈춰서 그 틈에 거리를 벌릴 수 있습니다.
- 좀비를 없애는 방법은 없습니다 — **오직 도망치는 것**만이 살아남는 방법입니다. 이 앱은 러닝을 재밌게
  만드는 게 목적이라, 좀비를 잡거나 처치하는 요소는 일부러 빼뒀어요.
- 체력이 0이 되면 게임 오버, 언제든 "종료" 버튼으로 직접 러닝을 끝내고 결과(생존 시간·달린 거리)를 볼 수 있습니다.

## 내 좀비 경로 만들기 (계정 필요)

**누구나 계정을 만들어서** 앱 안에서 바로 지도를 그리고 저장하면, 배포/커밋 없이 다른 사람들이 바로
그 경로로 플레이할 수 있습니다. 내가 만든 지도는 나만 수정/삭제할 수 있고, 게임에서 쓰는(읽는) 건
로그인 없이 누구나 가능합니다. Supabase(무료) 프로젝트가 하나 필요합니다.

**서버 설정**

정확한 순서는 [배포 안내](DEPLOYMENT.md)를 따릅니다. `supabase/schema.sql`만 적용하는 것으로는
아이디 로그인과 그룹 기능이 모두 준비되지 않습니다. 인증용 Edge Function, 익명 인증,
복구 링크 허용 주소를 함께 설정해야 합니다. 다음 항목은 프로젝트 연결 값에 대한 참고입니다.

Supabase 무료 플랜은 프로젝트를 2개까지만 만들 수 있어서, 새 프로젝트 대신 기존 Supabase 프로젝트에
테이블만 하나 추가하는 방식을 씁니다 (완전히 별도 테이블이라 다른 데이터와 섞이지 않습니다).

1. 기존 Supabase 프로젝트의 **SQL Editor**에서 이 저장소의 `supabase/schema.sql` 내용을 그대로
   붙여넣고 실행합니다 (좀비 지도용 `zombie_maps`, 그룹 방용 `game_rooms`/`room_players`, 아이디↔이메일
   매핑용 `profiles` 테이블을 만들고, 지도는 로그인한 본인만 수정/삭제할 수 있게 권한을 겁니다). 이
   파일은 여러 번 실행해도 안전하니, 파일이 업데이트되면 다시 실행해주면 됩니다.
   (계정에 Supabase 프로젝트가 여러 개 있다면, 꼭 이 앱이 실제로 쓰는 프로젝트에서 실행해야 해요 —
   관리자 화면 하단에 "연결된 저장소: xxxxx" 라고 프로젝트 ID가 표시되니 헷갈리면 그걸로 확인하세요.)
2. 배포 워크플로우(`.github/workflows/deploy.yml`)에 프로젝트 URL과 anon(publishable) 키가 이미
   들어있어서 별도 설정 없이 바로 배포에 반영됩니다.
3. 로컬 개발용으로도 쓰려면 `zombie-run/.env.local`에 같은 값을 넣어주세요 (git에는 안 올라감).
   ```
   VITE_SUPABASE_URL=...supabase.co
   VITE_SUPABASE_ANON_KEY=...
   ```
   (새 프로젝트를 새로 만드셨다면 그 프로젝트의 Settings → API에서 값을 복사해 대신 넣으세요.)
4. 이메일 확인 설정은 현재 프로젝트의 운영 정책을 유지합니다. 프로필 생성 트리거는 이메일
   확인 대기 중에도 프로필을 만들며, 로그인 권한은 Supabase Auth가 검증합니다.
5. **비밀번호 찾기가 동작하려면 필수**: Supabase 대시보드 **Authentication → URL Configuration**에서
   이 앱의 배포 주소(`https://minable17-glitch.github.io/zombie-run/`)를 **Site URL** 또는
   **Redirect URLs**에 추가해주세요. 등록 안 하면 비밀번호 재설정 메일의 링크를 눌러도 엉뚱한
   곳으로 가거나 거부됩니다. 로컬 개발용으로 `https://localhost:5173/`도 같이 추가해두면 좋아요.

**사용법**
0. 시작 화면 맨 아래 "🛠️ 내 좀비 경로 만들기"를 누르면 로그인/계정 화면이 뜹니다. 처음이면 **"계정
   만들기"** 탭에서 아이디(영문/숫자/밑줄 3~20자)·이메일·비밀번호로 가입하고, 이미 있으면 **"로그인"**
   탭에서 아이디/비밀번호로 로그인하세요 (한 번 로그인하면 계속 로그인 상태로 유지되고, 화면 오른쪽 위
   🔓 버튼으로 로그아웃할 수 있어요). 가입할 때 넣은 이메일은 화면에 보이지 않고, 나중에 비밀번호를
   잊어버렸을 때만 쓰입니다 — **"비번 찾기"** 탭에서 아이디를 입력하면 그 이메일로 재설정 링크를
   보내드리고, 링크를 누르면 새 비밀번호를 설정하는 화면이 뜹니다.
1. 로그인하면 이어서 위치 권한을 요청합니다.
2. 지도 이름을 정하고, 플레이 반경(빨간 원)을 고릅니다. 중심 위치는 꼭 지금 있는 곳이 아니어도 돼요 —
   지도를 손가락으로 움직이거나 확대/축소해서 원하는 곳으로 이동한 뒤 탭하면 중심(🏁)이 그리로 옮겨집니다.
   다 됐으면 "구역 확정하고 경로 그리기"를 누릅니다.
3. 그 구역 안에서 지도를 탭해 점을 찍어 경로를 그립니다 (구역 밖을 탭해도 자동으로 구역 안쪽으로
   당겨져요). 찍은 점마다 번호가 매겨지고, 지금까지 찍은 경로의 총 거리(예: 1.2km)가 실시간으로
   표시됩니다. 잘못 찍었으면 "점 취소"로 마지막 점 하나만, "이 경로 취소"로 지금 그리는 경로 전체를
   지울 수 있어요. "이 경로 완료"로 저장하면 그 경로 위를 좀비 1마리가 왕복 순찰합니다 — 여러 경로(좀비)를
   계속 추가할 수 있습니다.
4. "이 지도 저장하기"를 누르면 바로 데이터베이스에 저장됩니다 (내 계정 소유로 저장됨).

"구역" 단계에는 **내가 만든** 지도 목록만 보여서(다른 사람 지도는 여기서 안 보이고 편집도 못 함,
게임에서 쓰는 것만 가능), ✏️로 불러와 수정(경로 추가/삭제, 반경 조정 후 다시 저장)하거나 ✕로 삭제할
수 있습니다. 화면 오른쪽 위 "←" 버튼은 경로 그리기 중이면 구역 설정 단계로 한 단계만 돌아가고, 구역
설정 단계에서 누르면 화면을 완전히 나갑니다(폰의 뒤로가기로도 똑같이 동작해요).

이후 그 반경 안에서 게임을 시작하면 자동으로 이 순찰 경로가 적용되고, 자유/제한구역 모드 선택은
무시됩니다(그 지도의 반경으로 제한구역 모드가 강제 적용됨). Supabase 설정이 없으면 이 화면에서 저장만
비활성화될 뿐, 게임 자체는 평소대로(자유/제한구역 모드) 동작합니다.

## 알려진 한계 (다음 단계 후보)

- 실제 GPS 오차(도심/실내에서 5~20m 수준) 때문에 붙잡힘 판정이 예민하게 느껴질 수 있어요. 필드 테스트 후
  `CATCH_RADIUS_M` 값을 조정하는 걸 권장합니다 (`src/App.jsx` 상단 상수).
- 화면이 꺼지거나 백그라운드로 가면(특히 iOS Safari) GPS 추적이 끊길 수 있습니다. 항상 화면을 켜둔 채
  플레이하는 걸 전제로 합니다.
- 백그라운드 추적, 설치형 PWA, 리더보드(Supabase 연동) 등은 아직 없습니다.
